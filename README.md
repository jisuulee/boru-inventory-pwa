# 보루 재고조사

갤럭시 Android Chrome용 재고조사 PWA입니다. 제품과 조사 데이터는 브라우저 IndexedDB에 저장됩니다.

## 실행

Node.js 22.12 이상에서 실행합니다.

```sh
npm ci
npm test
npm run build
npm run preview
```

개발 중에는 `npm run dev`를 사용합니다. 오프라인 설치를 확인하려면 빌드 결과인 `dist` 전체를 HTTPS 웹 호스팅에 올리거나 Android Chrome에서 HTTPS 배포 주소를 엽니다. PC의 일반 HTTP 내부 IP 주소에서는 서비스 워커 설치를 확인할 수 없습니다.

## 갤럭시 Android Chrome 확인 절차

1. Chrome에서 HTTPS 주소를 엽니다. 상단에 **오프라인 준비 완료**가 뜨면 Chrome 메뉴에서 **홈 화면에 추가** 또는 **앱 설치**를 선택합니다.
2. **제품 추가**에서 예를 들어 ‘에쎄 수 0.1’, ‘레종 프렌치블랙’, ‘레종 프렌치블루’를 등록합니다. **제품**에서 이름이나 별칭을 수정합니다. 검색창에서 ‘프렌치’와 오타가 있는 ‘프렌치블렉’을 각각 검색합니다.
3. **새 조사 → 시작**을 누릅니다. 전 품목이 미확인인지 확인합니다. ‘에쎄 수 0.1’에 수량을 0으로 설정하고 확인 완료에 포함되는지 봅니다. 이어 2 추가, 1 차감, 3으로 설정을 적용하면 각각 2, 1, 3보루가 되어야 합니다. **이력**에서 마지막 변경을 되돌리면 1보루가 됩니다.
4. **음성 시작**을 눌러 마이크를 허용합니다. “에쎄수 0.1”이라고 말하고 수량을 듣습니다. 화면에 **듣고 있어요**가 다시 뜨면 “2보루 추가”라고 말합니다. 3보루가 되어야 합니다. “5보루로 변경”은 5보루로 설정합니다. “2보루”만 말하면 저장 없이 동작을 다시 물어봅니다.
5. “레종 프렌치”라고 말해 후보를 띄웁니다. 정확한 제품명을 다시 말하거나 화면에서 제품을 선택합니다. 음성 응답 도중 인식이 멈추고, 응답이 끝난 뒤 다음 명령을 받는지 확인합니다. 손님 응대 중에는 **음성 중지**, 응대 후에는 **음성 시작**을 누릅니다. 화면 전환 후에도 직접 다시 시작할 수 있습니다.
6. **새 조사**를 시작해 수량이 모두 미확인으로 표시되는지 확인합니다. **이력**에서 이전 조사를 선택하면 이전 수량과 변경 기록이 다시 표시됩니다.
7. 비행기 모드를 켜고 설치한 앱을 닫았다 다시 엽니다. 검색, 수동 입력, 이력 조회가 되는지 확인합니다. Chrome 음성 인식에는 네트워크가 필요할 수 있습니다. 한국어 음성 출력은 기기의 음성 엔진과 언어 설정을 사용합니다.
8. **설정 → 백업 다운로드** 후 제품이나 수량을 하나 변경합니다. **백업 복원**에서 다운로드한 JSON을 선택하고 **교체 및 복원**을 누릅니다. 백업 당시 데이터가 돌아오는지, 잘못된 파일에서 기존 데이터가 유지되는지 확인합니다.

음성으로 제품명을 먼저 조회하고 이어서 제품명 없이 수량 명령을 말할 수 있습니다. 제품이 확실한 수량 변경은 즉시 저장합니다. 미확인 제품에 처음 추가한 수량은 첫 조사 수량으로 기록됩니다. 처음 차감하기 전에 수량을 먼저 입력하세요. 마이크가 반복해서 끊기거나 권한 오류가 발생하면 앱에 재시작 버튼이 표시됩니다. Chrome의 Android 연속 인식 제약을 보완하기 위해 인식이 끊긴 뒤 재시작을 시도합니다.


마이크 동의가 반복되면 주소창 왼쪽의 사이트 정보에서 이 사이트의 마이크 권한을 확인하세요. Chrome이 아직 권한을 요구한다고 보고하면 앱은 자동 재요청을 멈춥니다.
